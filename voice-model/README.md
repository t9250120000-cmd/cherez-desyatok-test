# Локальное распознавание речи (разговор с Бульком)

Файлы загружаются в приложение только по кнопке взрослого («Кабинет родителя → Настройки → Разговор с героем») и кладутся в отдельный кэш устройства `voicemodel-ru-v1`. Распознавание идёт на устройстве; речь не отправляется в сеть и не сохраняется.

- `encoder.int8.onnx`, `decoder.int8.onnx`, `joiner.int8.onnx` — модель sherpa-onnx-small-zipformer-ru-2024-09-18 (k2-fsa/sherpa-onnx, GitHub releases `asr-models`), int8. SHA-256: encoder 75653125…d085, decoder 43575276…4696, joiner a93e0afc…23f1.
- `grammar.json` — закрытый словарь: числа 0–20 (с «я думаю/это/будет/…»), да/нет, помоги, повтори, дальше, стоп; токены BPE модели. Генератор — Claude, tools/asr/ в облачной копии; при изменении фраз пересоздать.
- `../vendor/ort/` — onnxruntime-web 1.29.0 (npm, лицензия MIT): `ort.wasm.min.js`, `ort-wasm-simd-threaded.mjs/.wasm`.

Перед публикацией в магазине проверить и указать лицензии модели и onnxruntime-web в разделе «О программе».
